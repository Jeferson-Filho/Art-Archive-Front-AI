# Block 2 — Alt Text: Alternative Text Generation via AI

Alt Text is a textual description of the artwork's image, generated by the multimodal LLM. It is stored in the database together with the historical context and comparative analysis and applied to the image's `alt` attribute.

---

**RF-011 — Alt Text generation via LLM**

The LLM must generate, for each artwork, a descriptive and educational alternative text that describes the image's visual content (represented elements, composition, predominant colors, perceptible technique). The generation must use, as input, the artwork's image together with its metadata provided by the Harvard Art Museums API: title, artist, technique, culture, and period. Every successfully generated Alt Text must begin with the standard disclosure message: **"The text was generated by an AI system and may contain inaccuracies."**, followed by the description itself.

**Scenario 011.1 — Successful generation**

```gherkin
Given the back-end receives a generation request for an artwork with a valid image and its metadata (title, artist, technique, culture, and period)
When the LLM processes the image together with this metadata
Then the back-end returns a non-empty Alt Text
And the Alt Text begins with the standard disclosure message "The text was generated by an AI system and may contain inaccuracies."
And the remainder of the text describes visual elements of the image (figures, colors, composition, or technique)
```

**Scenario 011.2 — Incomplete metadata**

```gherkin
Given the back-end receives a generation request for an artwork whose metadata from the Harvard Art Museums API is missing one or more of the fields (title, artist, technique, culture or period)
When the LLM processes the request with only the metadata fields that are present
Then the back-end returns an alt text based only on the fields present
And the Alt Text begins with the standard disclosure message "The text was generated by an AI system and may contain inaccuracies."
And the LLM MUST NOT create, infer, or guess information to fill in a missing field
And the portion of the text that would depend on a missing field is simply not generated
And it does not return an error due to the absence of fields
```

**Scenario 011.3 — Generation failure**

> Related RFs/RNFs: RF-013

```gherkin
Given the back-end receives a generation request for an artwork
When the AI API call fails, or the artwork's image is invalid or does not exist
Then the back-end returns the standard message "Was not possible to generate an alt text for this image." as the Alt Text
And this message is not persisted in the database
And a new generation attempt is made the next time the artwork is visited
```

---

**RF-012 — Applying the Alt Text to the artwork's image**

> Related RFs/RNFs: RF-011, RF-013

The front-end must apply the generated Alt Text to the `alt` attribute of the artwork's `<img>` element on the detail page. The attribute must be filled with the content from the database when available; when it is not yet available, generation is triggered on demand instead of falling back to a generic placeholder.

**Scenario 012.1 — Alt Text available**

> Related RFs/RNFs: RF-013

```gherkin
Given the artwork has Alt Text stored in the database
When the front-end renders the artwork's image
Then the img tag's alt attribute contains the AI-generated text
And the alt attribute is neither empty nor absent
```

**Scenario 012.2 — Alt Text not yet generated**

> Related RFs/RNFs: RF-011, RF-013

```gherkin
Given the artwork does not yet have Alt Text stored in the database
When the front-end renders the artwork's image
Then the back-end triggers a dedicated AI API call to generate the Alt Text
And the generated Alt Text is applied to the img tag's alt attribute once ready
And, if the generation fails, the standard fallback message "Was not possible to generate an alt text for this image" is applied to the alt attribute instead
And the alt attribute is neither empty nor absent
```

---

**RF-013 — Independent generation of the Alt Text**

> Related RFs/RNFs: RF-011, RF-012

The Alt Text is generated through its own dedicated AI API call. Once successfully generated, the Alt Text is persisted in the database under the artwork's ID.

**Scenario 013.1 — Independent generation call**

> Related RFs/RNFs: RF-012

```gherkin
Given the artwork's Alt Text is not yet present in the database
When the back-end triggers its generation
Then a dedicated AI API call is made exclusively for the Alt Text
```

**Scenario 013.2 — Persisting the generated Alt Text**

> Related RFs/RNFs: RF-011

```gherkin
Given the Alt Text has been successfully generated for an artwork
When the back-end persists the result
Then the Alt Text is recorded in the database under the artwork's ID
And it becomes available for future visits without needing a new AI API call
```
